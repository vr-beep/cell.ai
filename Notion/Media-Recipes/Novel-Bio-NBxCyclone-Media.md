# Novel Bio NBxCyclone Media

## NBx CyClone Growth Media

Optimized for rapid plasmid production in *V. natriegens*.

| Component | Concentration |
|---|---|
| Yeast extract | 15 g/L |
| Vegetable tryptone | 2.5 g/L |
| Magnesium sulfate (anhydrous) | 4 g/L |
| Sodium chloride | 22.5 g/L |
| Dipotassium phosphate (K2HPO4) | 3 g/L |
| Tris buffer | 150 mM |
| **pH** | **6.4** |

### Notes

- Sterilize via 0.2 um filtration (not autoclaving)
- Animal-free formulation (vegetable-derived tryptone)
