# Overview

Phase 1 of the hackathon will focus on research and developing a clear, actionable game plan. Teams will review relevant background material, define the problem space, align on goals, and outline their proposed approach. In Phase 2, we'll split into three parallel tracks to execute on those plans. Each track can support up to two teams of four participants.

# Phase 1: Plan

Develop a game plan for each track by reviewing the biology of Vibrio Natriegens, surveying the literature, and studying best practices using Elnora.

- **Track A:** What 3 media components are most impactful to optimize? What dilution ranges should we try? Is a DOE appropriate or a different strategy given the limitations of your experimental setup? What media components cause precipitation and is there a way to design against that?

See: [Vibrio Natriegens Materials and Resources](Vibrio-Natriegens-Materials-and-Resources.md)

# Phase 2: Build

### Track A: Develop an agentic closed loop workflow to optimize media composition

Build an autonomous workflow using Monomer's MCP to iteratively vary media components, generate growth curves, measure outcome using a platereader, and update the next experiment end-to-end. All on REAL cells. Integrate with Elnora's CLI/MCP to fully close the loop on deciding what *media formulation* to try next.

This track will have two steps:

1. **Tutorial of Monomer's System (1 hour)** — Monomer Staff will walk both teams through running the same experiment to determine optimal seeding density of Vibrio Natriegens on the workcell
2. **Experimental Execution (24 hours)** — From what you learned using Elnora, and now with familiarity of the system, you will design iterative experiments to BUILD THE BEST MEDIA! Monomer will provide components and coaching on how best to do this for both teams using the resources available at Monomer HQ.
