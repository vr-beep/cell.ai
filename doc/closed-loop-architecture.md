# Cell.ai Closed Loop — как это работает

## Схема

```
       ┌──────────────────────────────────────────────┐
       │                                              │
       ▼                                              │
  ┌─────────┐     ┌──────────┐     ┌──────────┐     ┌─┴────────┐
  │  ROBOT  │ ──► │ RESULTS  │ ──► │  BRAIN   │ ──► │  NEW     │
  │  grows  │ OD  │  growth  │     │ (Claude) │     │ RECIPE   │
  │ bacteria│     │   CSV    │     │          │     │          │
  └─────────┘     └──────────┘     └────┬─────┘     └──────────┘
      ▲                                 │
      │                                 │ decides:
      │                                 ▼
      │                        ┌─────────────────┐
      │                        │ BayBE (explore) │
      │                        │       or        │
      │                        │ Elnora (knowl.) │
      │                        └─────────────────┘
      │                                 │
      └─────────────────────────────────┘
                 robot runs new plate
```

## Closed loop по шагам

1. **Робот** растит *V. natriegens* на пластине с разными рецептами среды
2. **Результаты** (скорость роста по OD600) попадают в `data/{plate_id}_growth.csv`
3. **Claude-оркестратор** смотрит на результаты и решает что дальше:
   - **BayBE** → если данных достаточно, байесовская оптимизация (GP) предлагает следующие точки
   - **Elnora** → если данных мало, спрашиваем литературу / биолога-AI
4. Новый рецепт → **компилятор** переводит г/л → мкл трансферов → **робот** варит новую пластину
5. Повторяем, пока confidence intervals не сойдутся (обычно 2–3 раунда)

## Состояние и дашборд

- Всё состояние живёт в двух JSON файлах в `POC/closed-loop/data/`:
  - `orchestrator_state.json` — полный диалог Claude + метаданные раундов (crash recovery)
  - `orchestrator_log.json` — лёгкий progress log для дашборда
- **Streamlit дашборд** (`app.py`) поллит log каждые 3 секунды и показывает прогресс, heatmap пластины, growth curves и BayBE proposals в реальном времени

## Запуск

```bash
./launch.sh <PLATE_ID>
```

или кнопка **Launch Closed Loop** в Streamlit дашборде.
